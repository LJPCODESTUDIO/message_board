# message_board
Installation instructions
1. Make sure the mongodb server is running.
2. In the terminal, Type NPM install to install the backend dependencies.
3. type node server.js to run the backend server

4. Once the backend is running, open a new terminal.
5. In the new terminal type cd frontend to switch to the frontend server.
6. In the frontend server folder, type NPM install to install the frontend dependencies.

7. In the root message_board folder, create a new .env file named ".env"
8. You can use .env.example to see how to structure your .env file. Just copying it to the .env will be enough to get it to work for demonstration purposes, though this is not secure for real life deployment.
